# synrise25 的 Homebrew tap

## 安装 v2term

支持 macOS、Linux 的 Intel／AMD 64 位和 ARM64 设备。

```sh
brew install synrise25/tap/v2term
```

更新：

```sh
brew update
brew upgrade synrise25/tap/v2term
```

公式每六小时自动同步 [v2term 的最新稳定发行版](https://github.com/synrise25/v2term/releases/latest)，也可在 Actions 中手动运行「同步 v2term」。

项目说明与使用方法见 [v2term](https://github.com/synrise25/v2term)。
